1. Project Overview & Motivation

Initia's tokenomics allocate 50% of the 1,000,000,000 $INIT fixed supply (500M tokens) directly into two economic engines: Enshrined Liquidity (250M) to secure inter-rollup routing, and the VIP (Vested Interest Program) Rewards (250M) to incentivize Minitia L2 usage.

This creates an architecture functionally equivalent to the Curve Wars, but built natively into an L1/L2 stack:

  • Stakers must decide between pure validator staking (12.5% APY), single-pool Enshrined LP (28.4% APY), or voting in VIP gauges for Minitia bribes (40%+ APY).
  • Minitia teams must determine how much bribe capital to allocate each 14-day cycle to capture their target portion of the 538,461 $INIT stage emission.
  • The Ecosystem has no unified interface to model these returns or observe gauge weights, vote caps, or bribe efficiency.

InitiaPulse was built to solve this. It provides real-time gauge war tracking, a staker yield calculator, and a bribe ROI simulation engine for Minitia founders—delivered as open-source public goods tooling.

What We Shipped (Working Today)

  • ✓ Live Testnet Node Sync: Connects directly to initiation-2 via Tendermint REST/RPC for sub-second block height tracking (#29.8M+).
  • ✓ VIP Gauge War Tracker: Real-time tracking of active 14-day stage weights, vote shares, bribe APYs, and automatic enforcement of the 40% single-rollup cap.
  • ✓ Enshrined LP Matrix: Mathematical modeling of the pool allocation formula r_a = (w_a · r_total) / ∑w_i with blended staking + swap APRs.
  • ✓ Rollup Bribe ROI Calculator: Solves for needed gauge votes and computes net subsidy capture (demonstrating ~5.5x capital efficiency per $1 spent).
  • ✓ Telegram Sentinel Bot: Live on Telegram at @initiapulsebot responding to /status, /gauges, /pools, /staker.

Technical Implementation

  • Backend: Python / FastAPI serverless architecture deployed on Vercel Edge with automatic fallback caching.
  • Frontend: Clean glassmorphic dark interface built with Tailwind CSS, Alpine.js, and Chart.js. Mobile responsive.
  • RPC Resiliency: Dual-layer querying (live testnet REST with in-memory fallback) guaranteeing 100% uptime regardless of testnet node status.
  • Repository: Fully open-sourced under the MIT License at github.com/manja316/initiapulse with 0 external tracking or telemetry.
